# Northwind data

`instnwnd.sql` is the canonical Northwind SQL Server sample script published in
Microsoft's [`sql-server-samples`](https://github.com/microsoft/sql-server-samples/tree/master/samples/databases/northwind-pubs)
repository. It is embedded into the API assembly and executed once when the
Aspire-managed `northwind` database is empty.
